# u-cursos-liquid-glass
Extensión de chrome/edge para aplicar un modo oscuro estilo liquid glass a u-cursos. Programado con Gemini con fines de aprendizaje.
Está hecho para el tema oscuro de la app web.

Disclaimer: Este proyecto es una modificación visual estrictamente local (theming) basada en la manipulación del DOM y CSS. No realiza ingeniería inversa, ni accede o interfiere de ninguna manera con los servidores de U-Cursos.
